# Settings Plugin

The Settings Plugin is a Minecraft plugin that allows players to toggle various game settings directly in-game. This plugin provides a user-friendly graphical interface to manage settings such as mob spawning, hiding player names when invisible, and toggling night vision. It is designed to enhance the player experience by giving them quick access to essential game settings.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/EnderDevelopment/SettingsPlugin/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to load the plugin.

## Use

1. Open the in-game chat.
2. Type `/settings` and press Enter.
3. The Settings GUI will open, displaying various toggles.
4. Click on any item in the GUI to toggle its setting.
5. The status of each setting will update immediately and a message will be displayed in the chat.
